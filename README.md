# `sudo`

The program to concede administrative permissions
to users according to various rules.

The GNU project and the Android wrapper are in
the corresponding subdirectories.

## Installation

Installation instructions for the two
projects are in the relative subdirectories.

The
[universal recipe](
  https://github.com/themartiancompany/ur-docs/tree/master/docs/UniversalRecipes.md)
for this project collection has been officially published on the
the uncensorable and undeletable
[Ur](
  https://github.com/themartiancompany/ur)
user repository and application store as
`sudo`.
The source code is published on the
[Ethereum Virtual Machine File System](
  https://github.com/themartiancompany/evmfs)
so it can't possibly be taken down.

To install it from there just type

```bash
ur \
  sudo
```

A censorable HTTP Github mirror of the recipe published there,
containing a full list of the software dependencies needed to run the
tools is hosted on
[sudo-ur](
  https://github.com/themartiancompany/sudo-ur).

A censorable binary package has been published on the
[Fallback User Repository](
  https://github.com/themartiancompany/fur)
and it can be installed with

```bash
fur \
  sudo
```

Be aware the mirrors could go offline any time as Github and more
in general all HTTP resources are inherently unstable and censorable.

## Documentation

Documentation for the platform projects can be found in the
corresponding subdirectories, Ur documentation is available
on its website and the manual can be consulted with the
`man ur` command.
